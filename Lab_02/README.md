Welcome to this section of the repository! 
This folder contains foundational C programs focused on variable manipulation, basic financial math, and character encoding.
These exercises demonstrate core programming logic, such as data swapping techniques and working with ASCII values.

 📂 Programs Included

Program 1: Swapping variables *with* a temporary third variable.
    
Program 2: Swapping variables *without* a third variable 
    
Program 3: Simple Interest Calculator

Program 4: ASCII(American Standard Code for Information Interchange) Value Printer.
