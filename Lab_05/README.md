# C Decision & Logic Programs

A collection of foundational C programs focused on conditional logic, loops, and mathematical checks.

## 📂 Programs List

Program 1: Largest of Three Numbers – Uses nested conditional statements to find the maximum value among three inputs.

Program 2: Leap Year Checker– Implements divisibility rules to determine if a given year is a leap year.

Program 3: Prime Number Checker – Utilizes loops to verify if a number has any factors other than 1 and itself.

Program 4: Sum of N Natural Numbers– Computes the cumulative sum of numbers up to $N$ using a loop formula.
