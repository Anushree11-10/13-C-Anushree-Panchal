# C Math & Number Logic Programs

A collection of foundational C programs focused on number properties, recursion, loops, and mathematical algorithms.

## 📂 Programs List

Program 1: Armstrong Number Checker – Verifies if a number equals the sum of its own digits raised to the power of the number of digits.

Program 2: Palindrome Checker – Reverses an integer to check if it reads the same forward and backward.

Program 3: Factorial Calculator – Computes the product of all positive integers up to a given number using loops.

Program 4: GCD Finder – Calculates the Greatest Common Divisor of two numbers .

Program 5: Fibonacci Series Generator – Prints the sequence of numbers where each number is the sum of the two preceding ones.
