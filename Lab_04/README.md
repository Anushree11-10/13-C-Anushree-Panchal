 **Basic C Programs**
 
A collection of foundational C programs covering loops, data types, arithmetic, and conditional logic.

## 📂 Programs List

Program 1: Multiplication Table – Generates a multiplication table for a user-specified number using loops.

Program 2: Size of Data Types – Uses the `sizeof()` operator to print the memory allocation of standard C data types.

Program 3: Quotient & Remainder – Computes division results using the division (`/`) and modulus (`%`) operators.

Program 4: Alphabet Checker – Uses conditional statements to verify if an input character belongs to the alphabet.
