C Programming: Conditional Logic & Decision Making

Welcome to this section of the repository! 
This folder contains fundamental C programs focused on **conditional statements (`if-else`, `else-if` )**. 
These exercises demonstrate how to implement decision-making logic in C to evaluate conditions, check numbers, and calculate grades.

## 📂 Programs Included

Program 1: Grade and Percentage Calculator – Accepts student marks, computes the total percentage, and assigns an academic grade based on specific score brackets using `if-else`.

Program 2: Find Maximum of Two Numbers – Compares two numerical inputs and determines which value is larger.

Program 3: Voting Eligibility Checker – Checks if a user's age satisfies the legal requirement (typically 18+) to vote.

Program 4: Even or Odd Checker– Determines whether an integer is even or odd using the modulus operator (`% 2`).

Program 5: Positive or Negative Checker – Evaluates an inputted number to check if it is greater than, less than, or equal to zero.
