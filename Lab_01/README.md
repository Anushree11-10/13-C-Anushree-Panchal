
C Programming Basics

Welcome to this repository! This folder contains a collection of fundamental C programming concepts and foundational exercises, 
ranging from basic arithmetic operations to geometric calculations and temperature conversions. It is designed as a starter kit 
for mastering the syntax and logic of the C language.

📂 Programs Included :

• Program 1: First C Program – A basic introduction to C syntax, typically demonstrating standard output using printf.

• Program 2: Addition of Two Numbers – Accepts user inputs to calculate and display the sum of two integers or floating-point numbers.

• Program 3: Subtraction of Two Numbers – Implements basic arithmetic subtraction between two numerical values.

• Program 4: Multiplication of Two Numbers – Demonstrates how to multiply variables and output the product.

• Program 5: Division of Two Numbers – Handles numerical division, showcasing integer vs. float division handling.

• Program 6: Modulus Calculation – Uses the % operator to determine the remainder of a division between two integers.

• Program 7 & 8: Area and Perimeter of Geometrical Shapes – Practical applications of math formulas to compute the area and perimeter/circumference of shapes like squares, rectangles, or circles.

• Program 9: Fahrenheit to Celsius Conversion – Implements the temperature conversion formula to translate degrees Fahrenheit into Celsius.
